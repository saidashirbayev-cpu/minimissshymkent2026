Firebase Google OAuth баптауы

Сайтқа нақты Firebase аутентификациясын қосу үшін кодтағы firebaseConfig ключевой объектін өз жобаңыздың кілттерімен алмастырыңыз: 

const firebaseConfig = {
  apiKey: "YOUR_ACTUAL_API_KEY",
  authDomain: "your-app.firebaseapp.com",
  projectId: "your-app-id",
  storageBucket: "your-app.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
  • Firebase Console -> Authentication -> Sign-in method -> Google (Іске қосыңыз).
  • Authorized Domains бөліміне өз доменіңізді / preview URL қосыңыз.
  • Егер API кілті енгізілмесе, сайт автоматты түрде **Интерактивті Симуляция Режимінде** дауыс береді.
